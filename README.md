Collection of academic projects in Electrical Engineering, focusing on high‑voltage network analysis, Ybus matrix construction, power system resilience assessment, FEM modeling of grounding electrodes, and FEMM simulations of magnetic fields.
The repository includes MATLAB scripts, numerical models, FEM/FEMM simulations, and technical documentation.

Project Index
1. Resilience Assessment
Resilience‑oriented methodology for identifying critical components in power systems under adverse events.
Includes N‑1 security analysis, power flow studies, vulnerability metrics, and case studies (IEEE 9‑bus, IEEE 24‑bus RTS).

2. Ybus AT Network
Construction of the admittance matrix 𝑌𝑏𝑢𝑠 and impedance matrix 𝑍𝑏𝑢𝑠 for a portion of the Italian HV network (220/380 kV).
Includes line parameter calculation, transformer modeling, per‑unit conversion, and MATLAB scripts.

3. Grounding FEM
Finite Element Method analysis of grounding electrodes in homogeneous and layered soils.
Includes spherical, hemispherical, rod, and emerging electrodes, with step‑voltage evaluation and field distribution.

4. Magnetic Fields FEMM
FEMM simulations of magnetic fields generated by electrical conductors: Helmholtz coils, overhead HV lines, MV limiting reactors, and compact busbar ducts.
Includes analytical comparisons and electrodynamic force evaluation.

How to Navigate This Repository
This repository is organized into four main project folders, each containing documentation, reports, and supporting materials:
Resilience Assessment — Bachelor thesis on resilience-oriented methodologies for identifying critical components in power systems. Includes full PDF report and supporting documents.
Ybus AT Network — MATLAB-based construction of the Ybus and Zbus matrices for a portion of the Italian HV network.
Grounding FEM — FEM analysis of grounding electrodes in homogeneous and layered soils. Includes full project report.
Magnetic Fields FEMM — FEMM simulations of magnetic fields generated by electrical conductors. Includes full project report.

Each folder contains:
A README summarizing the project
The PDF report
