FEMM Analysis of Magnetic Fields Generated by Electrical Conductors
This project analyzes magnetic fields produced by different electrical conductor configurations using FEMM (Finite Element Method Magnetics). The study includes Helmholtz coils, overhead HV lines, medium‑voltage limiting reactors, and compact busbar ducts, with comparisons against analytical formulas and evaluation of electrodynamic forces.

Summary
This project provides a complete FEMM‑based analysis of magnetic fields generated by various electrical conductors. It includes comparisons with analytical formulas, evaluation of field uniformity, and computation of electrodynamic forces, offering insight into electromagnetic behavior in practical power engineering applications.
